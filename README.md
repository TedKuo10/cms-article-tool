# 文章排版轉換工具

把文章內容轉成符合公司 CMS 樣式規則的 HTML，方便複製貼進老舊 CMS。
**純前端、單一檔案、無任何相依套件**，所有處理都在使用者的瀏覽器本機完成，內容不會上傳到任何伺服器。

這是原本那段在 Google Colab 執行的 Python 轉換腳本的網頁版本，轉換規則完全比照原腳本（H2/H3 樣式、自動目錄、`<p>&nbsp;</p>` 間距、表格框線等）。

---

## 給同事：怎麼用

1. 開啟工具網址（見下方部署後的連結）。
2. **在左邊編輯區貼上內容**（建議直接從 Word 全選複製貼上，標題、粗體、連結通常會保留）。
3. 用上方工具列把標題標記好：
   - 選取標題那行 → 按 **H2**（中標題）或 **H3**（小標題）。
   - 一般內文用 **內文**；也可加 **粗體 / 斜體 / 清單 / 連結**。
4. 按 **「轉換 →」**，右邊會顯示套好樣式的預覽。
5. 按 **「複製內容（貼進 CMS）」**，再到 CMS 的編輯器直接 **貼上（Ctrl+V）** 即可。
6. 萬一某 CMS 貼上有狀況，可改按 **「下載 .html」** 取得檔案。

> 提示：標題層級（H2/H3）是自動產生「文章目錄」與標題樣式的依據，務必標記正確。

### 重要行為說明
- **H1 不會輸出**（比照原本的工具，文章大標通常由 CMS 文章標題另外設定）。若需要改成輸出 H1，請告知維護者。
- H2 標題色碼維持原腳本的 `#07788`（這是原腳本就有的值，未做更動）。
- 與原腳本相比，本版本**會保留粗體 / 斜體**，並**支援項目 / 編號清單**。
- 編輯器沒有「插入表格」按鈕；但如果貼上的內容含表格，轉換時仍會套用原本的表格框線樣式。

## 給維護者：部署到 GitHub Pages

1. 建一個 GitHub repo（例如 `article-formatter`），把 `index.html` 與 `README.md` 上傳並 push。
2. 進 repo → **Settings** → **Pages**。
3. **Source** 選 `Deploy from a branch`，Branch 選 `main`、資料夾 `/ (root)`，按 **Save**。
4. 等一兩分鐘，會得到網址：`https://<你的帳號>.github.io/<repo 名稱>/`
5. 把這個網址分享給同事即可。

之後要改樣式或規則，直接編輯 `index.html` 再 push，GitHub Pages 會自動更新。

---

## 本機測試

直接用瀏覽器打開 `index.html` 即可（本工具不需伺服器）。
若想模擬正式環境，也可在資料夾內執行：

```bash
python -m http.server 8000
```

然後開啟 `http://localhost:8000`。

## 技術說明（給維護者）

- 單一 `index.html`，UI + CSS + 轉換邏輯全內嵌，無外部 CDN 或套件。
- 編輯器為 `contenteditable`，工具列用 `document.execCommand`（現行瀏覽器仍支援；若日後失效需改用其他編輯器方案）。
- 轉換邏輯（`convertEditor` / `applyAutoTocAndSmooth` / `tableToHtml`）是原 Python 腳本對應函式的 JavaScript 移植。
- 複製採用 Clipboard API 寫入 `text/html`（rich paste）；不支援時自動退回 `execCommand('copy')` 備援。
